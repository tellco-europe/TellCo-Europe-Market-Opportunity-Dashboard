# TellCo-Europe-Market-Opportunity-Dashboard

The application translates market data into actionable steps through three primary views:

Where to focus: ranks target countries and outlines a recommended entry sequence using an eight-criterion scorecard that evaluates factors like offtakers, econonmics, and currency risk.

Why and which sector: quantifies the core commerical proposition by charting the gap between current customer power costs and hybrid solar alternatives, alongside a sector priority heatmap.
